2010 STREET FIGHTER
Faithful English Retranslation
Version 1.0

ABOUT
-----
This patch provides a faithful English translation of the original Japanese
Famicom version of 2010 Street Fighter.

Unlike the official North American localization, this translation preserves
the original Japanese storyline and terminology. Kevin Straker remains the
protagonist, and the story retains the Parasites, Armored Insects, Galaxy
Police, and other concepts from the Japanese release.

The official U.S. version substantially rewrote the story to connect the game
to the Street Fighter series. This patch does not use that rewrite.

FEATURES
--------
- Complete English translation of the Japanese Famicom version
- Original Japanese storyline and terminology retained
- Translated opening story sequence
- Reworked English text layout and scrolling
- Dialogue renderer and cursor fixes
- Selected technical bug fixes from the U.S. release
- Full start-to-finish playtesting

KNOWN QUIRK
-----------
Apostrophes in contractions can have slightly unusual spacing because the
original tile-based text renderer was not designed for English punctuation.
This is cosmetic only.
